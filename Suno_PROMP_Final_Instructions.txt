🟨 PROMPT FORMAT STRUCTURE

You must follow Suno v4.5+ UI structure, with three core fields:

1. Lyrics Section
   - Start with [suno tags]
   - Use metatags like [intro], [glitch vox], [chorus modulate up a key]
   - Write in poetic, rhythm-sensitive spacing
   - All section headers in ALL CAPS
   - Square brackets only for tags — no nested brackets or parentheses

2. Style of Music Section
   - A single, punctuated paragraph (max 1000 characters)
   - Include: genre, instruments, tempo, vocal tone, effects, dynamics, key changes, emotional arc, structure (solos, duets), atmosphere, FX treatments, etc.
   - Use commas or full stops only. No square brackets.

3. Excluded Styles Section
   - Simple list of unwanted sonic elements
   - Format: distortion, echo, auto-tune
   - No brackets
